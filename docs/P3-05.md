# P3-05 Reference Alignment — 工程验证记录

**日期：** 2026-10-12  
**状态：** 单帧三层对齐 PASS

## 1. 做了什么

使用相同的 YOLOv8n ONNX 模型，对 C++ 推理链路进行分层验证：

- C++ ONNX Runtime 与 Python ONNX Runtime 原始输出对齐
- C++ 自实现预处理与 Python OpenCV / NumPy 预处理对齐
- C++ 自实现 Decode + NMS 与 Ultralytics 最终检测结果对齐

测试模型输入为 FP32、NCHW、`[1,3,640,640]`，输出为 `[1,84,8400]`。

## 2. 为什么这样做

单纯运行成功并得到 Detection，不能证明预处理、Tensor 排列、模型调用或后处理算法正确。

因此采用逐层参考对齐，而不是只检查最终检测框。

## 4. 原理与问题定位

首次对齐时，C++ 和 Python 分别从 MP4 中读取第一帧，预处理结果有 235,252 个元素不同，最大绝对误差约为 0.011765。

随后将 C++ 读取的原始帧无损保存为 PNG，让 Python 使用该 PNG 进行预处理。

统一输入后，全部 1,228,800 个预处理元素完全相等。

结论：跨语言数值验证必须先保证输入数据完全一致，否则视频解码差异可能干扰对预处理算法的判断。

## 5. 面试追问与回答要点

**如何证明自实现 YOLO 后处理正确？**

不能只依赖输出看起来合理，应分别验证预处理 Tensor、原始模型输出和最终 Detection，并使用独立参考实现进行比较。

**为什么不能直接比较两个程序解码后的视频帧？**

相同视频文件不一定意味着两套解码环境产生逐像素相同的结果，应固定无损原始输入。

**为什么要分层验证？**

分层验证可以隔离误差来源，区分预处理、模型执行和后处理的问题。
